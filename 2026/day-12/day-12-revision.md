## Mini Self-Check

### Which 3 commands save you the most time?

* `ls -l` — quickly shows permissions and ownership
* `systemctl status` — tells me if a service is running
* `ps` — helps see active processes

---

### How do I check if a service is healthy?

1. Check status with `systemctl status`
2. Confirm process using `ps`
3. Inspect logs if needed

---

### How do I safely change permissions?

Make small changes and verify immediately.

Example:

```
sudo chmod 640 filename
```
